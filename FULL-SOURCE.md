# Полный исходный код RouteGhost × Organic Maps

Этот пакет включает **полный авторский код интеграции RouteGhost** и автоматические инструкции для получения **полного объединённого исходного дерева** Organic Maps + RouteGhost через GitHub Actions. Сам upstream Organic Maps в этой ZIP-копии **не включён**.

## Где получить все исходники одним архивом

1. Создайте новый пустой GitHub-репозиторий и загрузите туда содержимое данного ZIP (включая `.github`).
2. Откройте GitHub **Actions → Export Complete RouteGhost Source → Run workflow**.
3. Дождитесь завершения. В **Artifacts** скачайте `RouteGhost-Full-Source` — внутри будет `RouteGhost-OrganicMaps-Full-Source.tar.gz`.
4. Это будет объединённый исходный код Organic Maps и RouteGhost. Скрытые папки Git исключены для уменьшения размера, исходные файлы сохранены.
5. Чтобы попробовать собрать APK, запустите отдельно **Actions → Build RouteGhost (Organic Maps)**. Сборка не проверена на реальном Android SDK и может потребовать исправлений.

Исходник Organic Maps: https://github.com/organicmaps/organicmaps , версия `2026.11.11-39-android`.

## Важные ограничения

- Этот способ требует GitHub и сети для загрузки исходников на сервер GitHub. Android Studio на устройстве пользователя не нужна.
- Сборка и экспорт Organic Maps могут потребовать значительного места и времени; бесплатный runner может не справиться.
- Наличие полноценного исходного дерева не гарантирует успешную сборку APK — текущая интеграция не проходила полноценную сборку Android.
- В этой версии не реализована точная сегментация всех поездок на метро/автобусе/пешком: тип транспорта в некоторых случаях определяется приближённо.
- Для маршрутизации Organic Maps требуются региональные данные `.mwm`.
- Соблюдайте Apache 2.0 и другие условия лицензий Organic Maps, включая видимую атрибуцию проекта.
