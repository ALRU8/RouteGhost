# RouteGhost

RouteGhost — приложение для Android, с которым можно имитировать перемещение по маршруту или установить виртуальное местоположение в одной точке. Оно работает на основе Organic Maps: здесь можно искать места, строить пешеходные, автомобильные и транспортные маршруты, а затем воспроизводить выбранный путь с помощью GPS-симуляции.

Во время движения RouteGhost постепенно меняет координаты и скорость, добавляет остановки и случайные задержки. Например, пешеход может ненадолго остановиться, а транспорт — замедлиться или задержаться. Всё это моделируется автоматически, поэтому симуляция выглядит естественнее, чем простое перемещение точки с постоянной скоростью.

## Как это работает

Сначала в Organic Maps нужно выбрать начальную и конечную точки, построить маршрут и выбрать подходящий вариант. Затем нажать кнопку **GPS** на карте — откроется панель RouteGhost с управлением симуляцией.

В приложении есть три режима:

- **Маршрут.** GPS-точка движется по выбранному пути. Можно выбрать тип движения, включить случайные остановки и задержки, поставить симуляцию на паузу или остановить её.
- **Одна точка.** Можно указать широту и долготу, чтобы телефон передавал выбранное местоположение без движения.
- **Свой маршрут.** Можно загрузить GPX или GeoJSON либо вручную указать точки и способ передвижения: пешком, на машине, автобусе, метро, трамвае и другом транспорте. Вручную заданные точки соединяются прямыми отрезками.

RouteGhost передаёт координаты через механизм тестовой геолокации Android (**Mock Location**). Для этого в параметрах разработчика нужно выбрать RouteGhost в разделе «Приложение для фиктивных местоположений». После запуска симуляция может продолжаться в фоне, а управление доступно из приложения и уведомления.

Маршруты берутся из Organic Maps, поэтому для их построения нужны картографические данные выбранного региона. Если приложение не сможет получить геометрию маршрута, оно сообщит об этом вместо воспроизведения неверной траектории.

Скорости, ожидания и пробки в RouteGhost моделируются приблизительно: приложение не отслеживает реальные сигналы светофоров и не знает точные задержки транспорта. Для сложных поездок с пересадками точность симуляции зависит от того, какие данные о маршруте доступны в Organic Maps. Некоторые сторонние приложения также могут распознавать тестовую геолокацию или не использовать её.
