# RouteGhost

RouteGhost — Android-приложение на основе Organic Maps, которое подменяет GPS-положение телефона. Оно может вести точку по маршруту, построенному на карте, или удерживать одну заданную точку.

## Как это работает

1. В Organic Maps строится маршрут (пешком, на машине или на общественном транспорте), затем нажимается кнопка **GPS** на карте.
2. RouteGhost читает геометрию выбранного маршрута. Составной маршрут делится на участки по типам движения: пешком, автобус, метро и так далее.
3. Для каждого типа движения задаётся диапазон скорости. Движок строит временну́ю шкалу: скорость выбирается из диапазона, добавляются остановки, ожидание транспорта, пересадки, пробки и небольшой GPS-шум.
4. Фоновая служба передаёт получившиеся координаты через тестовые провайдеры геолокации Android (Mock Location), поэтому работа продолжается и при свёрнутом приложении.

Режимы: **Маршрут** (из Organic Maps), **Одна точка** (фиксированные координаты) и **Свой трек** (GPX, GeoJSON или точки вручную).

## Стек

- Java, Android SDK (интерфейс без XML-разметки, построен в коде)
- Organic Maps (Java SDK и JNI/C++ для геометрии маршрута)
- Android `LocationManager` Test Providers, Foreground Service
- Python-скрипт `apply_patch.py` встраивает код в исходники Organic Maps
- Gradle, GitHub Actions для сборки APK
