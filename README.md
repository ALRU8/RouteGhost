# RouteGhost × Organic Maps — интеграционный проект

Это **не APK** и не копия исходников Organic Maps. ZIP содержит интеграцию в официальное приложение Organic Maps, которую GitHub Actions накладывает на исходный код, собирая форк. Установка Android Studio пользователю не нужна.

## Что реализовано

- Весь картографический интерфейс, поиск, автомобильная, пешеходная и транспортная маршрутизация — из исходного Organic Maps.
- На карте появляется кнопка **GPS** (справа внизу). Если маршрут построен и выбран, кнопка берёт точки маршрута из `Framework.nativeGetRouteJunctionPoints(12.0)` и сохраняет локально. При пустой геометрии не выдумывает трек.
- Контрольная панель содержит **Маршрут**, **Одна точка**, **Свой маршрут**.
- Импорт GPX и GeoJSON, ручное задание списка координат и типа каждого участка.
- Имитация задержек, скоростей и пробок в виде вероятностной модели, основанной на имеющейся геометрии. Симуляция обновляется раз в секунду.
- Системный Android Mock Location через `LocationManager`, foreground service и управление из уведомления.

## Ограничения

**Organic Maps — офлайн-движок.** Нужные карты региона должны быть скачаны средствами самого Organic Maps (как обычно в приложении). Его нельзя без переделки ядра превратить в онлайн-маршрутизатор без карт. В RouteGhost отдельного меню скачивания не добавлено.

Поддержка маршрутов общественного транспорта зависит от реального покрытия Organic Maps. Модель событий **не знает текущие фазы светофоров, реальные пробки и точное время прибытия автобуса**. Профиль `Transit` содержит шаги метро, автобусов и т.д., но сейчас в RouteGhost при снятии геометрии определяется преобладающий вид транспорта; **точные границы пеших отрезков и всех пересадок не восстановлены**. Если `nativeGetRouteJunctionPoints()` не возвращает геометрию для выбранного транспортного варианта, воспользуйтесь GPX или собственным маршрутом. Не следует считать, что все транспортные поездки воспроизводятся точно.

При ручном маршруте между заданными точками используются прямые отрезки. Чтобы идти по настоящей дороге, сначала постройте маршрут в Organic Maps.

**Облачная сборка Органик Maps тяжёлая:** официальный проект рекомендует порядка 30 ГБ свободного места, а бесплатный GitHub-hosted runner может иметь меньше. Workflow является подготовленным сценарием, **полная сборка не проверена** на hosted runner в текущей среде. В случае нехватки диска потребуется более просторный runner или собственная машина.

## Получение APK без Android Studio

1. Создайте **новый пустой репозиторий** GitHub, не смешивая его с репозиторием старого RouteGhost 1.2.
2. Загрузите **содержимое** данного ZIP (папку `.github` нужно сохранить).
3. Откройте **Actions → Build RouteGhost (Organic Maps) → Run workflow**.
4. После успешного завершения скачайте артефакт `RouteGhost-OrganicMaps-APK`.
5. Установите APK и разрешите Android установку из выбранного источника. В настройках разработчика выберите установленное приложение как **Mock Location app**.

Для обновления исходной версии Organic Maps измените тег в `.github/workflows/build-android.yml`. Изменение upstream может потребовать адаптации `apply_patch.py`.

## Использование

**Маршрут:** в Organic Maps выбираете маршрут и вариант, нажимаете зелёную кнопку `GPS`, затем `Начать GPS`. Движок RouteGhost использует реальную геометрию, если нативная функция вернула точки. Если точек нет, отображает ошибку, не соединяет пункты прямой.

**Одна точка:** GPS → Одна точка → широта/долгота → Начать GPS.

**Свой маршрут:** GPS → Свой → импорт GPX/GeoJSON либо список координат (по одной строке `широта, долгота, MODE`). `MODE`: WALK, CAR, BUS, METRO, TRAM, TROLLEY, ELECTROBUS, TRAIN и др.

Для выключения: кнопка **Стоп** или **Стоп** в системном уведомлении.
